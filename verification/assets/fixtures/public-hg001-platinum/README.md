# HG001 Platinum Genomes germline case

This case compares the Genome in a Bottle HG001 v4.2.1 GRCh38 benchmark
against the Illumina Platinum Genomes 2.0.1 NA12878 callset. The samplesheet
fetches the inputs directly from the public NCBI GIAB archive and runs the
default xcmp engine.
