## hap.py compatibility

`hap-rs` reimplements the hap.py workflows in Rust. It keeps documented command
aliases and report schemas and removes the Python, C++, Java, and RTG runtime
dependencies. See the [quick start](./getting-started/quick-start/) and the
[verification matrix](./project/verification/).
